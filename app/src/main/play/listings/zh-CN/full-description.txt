移动配套应用 Record RCU 让你可以控制 Windows 电脑上的录制和直播！

有了 Record RCU，你可以隐藏 Action 的叠加窗口，再也不用打开它！

主要功能：
- 远程开始游戏录制或直播，也可以暂停录制或停止整个过程。
- 每秒告知：帧率（FPS）、视频录制时长（时、分、秒）、电脑可用空间（GB 和 MB）、在线直播状态（开/关）、游戏引擎（Vulkan、OpenGL 等）、麦克风和摄像头录制状态。
- 录制和直播界面上的 FPS 历史图表。
- 提示音：磁盘空间不足、按下“录制”“暂停”“停止”、达到设定的录制时长；可直接在录制界面关闭声音。
- 长时间未触摸时录制界面自动调暗。
- 自定义最小可用空间，低于该值时 Storage 变为红色。
- 可选择应用语言（Android 13 及更高版本）。
- 应用会自动找到电脑，并连接到你上次连接的那台。
- “高级版”：一次购买，永久有效，无需订阅，去除广告。

为确保应用正常工作，请确认已满足以下条件：
- 在 Windows 中将网络类型从“公用”改为“专用”（设置 -> 网络 -> 属性 -> 专用）；
- 在你的 Windows 上安装 Action Mirillis；
- 在 Windows 上运行 Action Mirillis，并在常规设置中勾选 "Enable Action! RCU"（可能需要重启该应用）；
- 安装并运行本应用；

要求：
- 移动设备和电脑必须连接到同一局域网。
