行動配套應用程式 Record RCU 讓你可以控制 Windows 電腦上的錄製和直播！

有了 Record RCU，你可以隱藏 Action 的覆疊視窗，再也不用開啟它！

主要功能：
- 遠端開始遊戲錄製或直播，也可以暫停錄製或停止整個過程。
- 每秒告知：影格速率（FPS）、影片錄製時長（時、分、秒）、電腦可用空間（GB 和 MB）、線上直播狀態（開/關）、遊戲引擎（Vulkan、OpenGL 等）、麥克風和攝影機錄製狀態。
- 錄製和直播畫面上的 FPS 歷史圖表。
- 提示音：磁碟空間不足、按下「錄製」「暫停」「停止」、達到設定的錄製時長；可直接在錄製畫面關閉聲音。
- 長時間未觸碰時錄製畫面自動調暗。
- 自訂最小可用空間，低於該值時 Storage 會變成紅色。
- 可選擇應用程式語言（Android 13 以上版本）。
- 應用程式會自動找到電腦，並連線到你上次連線的那台。
- 「進階版」：一次購買，永久有效，無須訂閱，移除廣告。

為確保應用程式正常運作，請確認已符合以下條件：
- 在 Windows 中將網路類型從「公用」改為「私人」（設定 -> 網路 -> 內容 -> 私人）；
- 在你的 Windows 上安裝 Action Mirillis；
- 在 Windows 上執行 Action Mirillis，並在一般設定中勾選 "Enable Action! RCU"（可能需要重新啟動該應用程式）；
- 安裝並執行本應用程式；

需求：
- 行動裝置和電腦必須連線到同一個區域網路。
