แอปคู่หูบนมือถือ Record RCU ช่วยให้คุณควบคุมการบันทึกและการถ่ายทอดสดบนพีซี Windows ของคุณ!

ด้วย Record RCU คุณสามารถซ่อนหน้าต่างโอเวอร์เลย์ของ Action และไม่ต้องเปิดมันอีกเลย!

ฟังก์ชันหลัก:
- เริ่มบันทึกหรือสตรีมเกมจากระยะไกล รวมถึงหยุดการบันทึกชั่วคราวหรือหยุดกระบวนการ
- แจ้งข้อมูลทุกวินาทีเกี่ยวกับ: อัตราเฟรม (FPS), เวลาบันทึกวิดีโอ (เป็นชั่วโมง นาที และวินาที), พื้นที่ว่างบนพีซีของคุณ (เป็น GB และ MB), สถานะการสตรีมออนไลน์ (เปิด/ปิด), เอนจินของเกม (Vulkan, OpenGL ฯลฯ), การบันทึกของไมโครโฟนและกล้อง
- กราฟประวัติ FPS บนหน้าจอบันทึกและสตรีม
- สัญญาณเสียง: พื้นที่ดิสก์เหลือน้อย การกด “บันทึก” “หยุดชั่วคราว” และ “หยุด” และเวลาบันทึกที่ตั้งไว้ โดยปิดเสียงได้บนหน้าจอบันทึกโดยตรง
- หรี่หน้าจอบันทึกเมื่อไม่มีการแตะเป็นเวลานาน
- กำหนดพื้นที่ว่างขั้นต่ำเอง ซึ่งหากต่ำกว่านี้ Storage จะเป็นสีแดง
- เลือกภาษาของแอป (Android 13 ขึ้นไป)
- แอปค้นหาพีซีเองและเชื่อมต่อกับเครื่องที่คุณเชื่อมต่อครั้งล่าสุด
- “พรีเมียม”: ซื้อครั้งเดียวใช้ได้ตลอดไป ไม่ต้องสมัครสมาชิก และลบโฆษณาออก

เพื่อให้แอปทำงานได้ โปรดตรวจสอบว่าคุณทำตามเงื่อนไขต่อไปนี้แล้ว:
- ใน Windows เปลี่ยนประเภทเครือข่ายจาก Public เป็น Private (การตั้งค่า -> เครือข่าย -> คุณสมบัติ -> ส่วนตัว)
- ติดตั้ง Action Mirillis บน Windows ของคุณ
- เปิด Action Mirillis บน Windows ของคุณและทำเครื่องหมายที่ "Enable Action! RCU" ในการตั้งค่าทั่วไป (อาจต้องรีสตาร์ทแอป)
- ติดตั้งและเปิดแอปนี้

ข้อกำหนด:
- อุปกรณ์มือถือและพีซีต้องเชื่อมต่อกับเครือข่ายภายในเดียวกัน
